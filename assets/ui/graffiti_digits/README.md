# Рисованные цифры счёта

Оригинальные векторные контуры по стилистическому референсу пользователя «FRESH»: наклонное граффити, зелёно-жёлтая заливка, чёрная объёмная тень и светлая внешняя обводка. Контуры написаны отдельно для цифр 0–9; дополнительно есть плюс, минус, знак умножения и десятичная запятая. Прозрачность, внутренние просветы и цвет сохранены в SVG. Системные шрифты не копируются.

Это игровой набор векторных глифов, не устанавливаемый TTF. `scripts/ui/graffiti_number.gd` составляет из него произвольные значения, сохраняет ширину цифровых позиций и уменьшает длинные значения до доступной ширины. Он используется в общем счёте, текущей серии, множителе и зачисленных очках. Обычные подписи и сообщение о потере серии остаются текстовыми.

Восстановление исходников: `python tools/build_graffiti_digits.py`, затем импорт Godot. Каждый файл имеет холст 312×348 и векторную систему координат 156×174. `tools/capture_graffiti_score.gd` сохраняет обзор и игровые кадры в `artifacts/graffiti_score/` и проверяет нулевой/большой счёт и границы отображения.

Для этого задания сначала был вызван встроенный imagegen; обе попытки завершились ошибкой соединения и не создали изображений. API/CLI-генерация не использовалась. Итоговые глифы созданы локально как векторные ресурсы интерфейса.

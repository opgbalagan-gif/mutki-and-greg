# Заставки собственных суперударов

Обновлено 25.09.2026. `mutki.ogv` — подготовка удара голыми руками; `greg.ogv` — подготовка круговой подсечки. Оба ролика созданы MiniMax H3 по новым образам героев: аниме-камера, размытый город, 9:16, около 5 секунд. Конвертация FFmpeg: 720×1280, 24 fps, Theora q6 / Vorbis q3.

Мутки: job `482a5ac7-3eb9-4aed-a4b5-6e528f95cc08`. Гриша: job `7c35f0b8-ad32-4a8b-87fd-63024486b51e`.

После ролика 0,18-секундный переход открывает текущую арену. Реальный урон наносит `ArenaSuperAttack`, а не видеоролик. На арене скрывается обычный спрайт только выбранного героя. Враги остаются активными; герой защищён до окончания приёма. После восстановления стойки запускается обычный idle с кадра 0. Последняя победа откладывает выход из миссии до окончания движения.

## Геймплейные исходники

Широкие ролики 16:9 на ровном зелёном фоне, неподвижная камера, без оружия и фиолетовой магии. Конечные кадры сняты из реальных игровых сцен `tools/render_super_idle.gd`: ровно тот же idle, который включается после суперудара. Финальные jobs MiniMax H3: Мутки `24b80470-b660-40c6-9901-8f8b0d32767f`, Гриша `f3d7ce82-9f83-4fae-8142-b3e39b7e7195`.

`tools/extract_gameplay_supers.py` удаляет зелёный фон, сохраняет общий масштаб и опорную точку, добавляет точный финальный игровой кадр и упаковывает прозрачные поля в AtlasTexture. Анимации: 63 кадра Мутки / 53 Гриши при 18 fps. Контакты: Мутки 8/17; Гриша 7/10. Каждый враг получает урон не более одного раза. Память активной анимации: 52,9 / 45,0 MiB, загружается только выбранный герой.

Исходные MP4, ключевые кадры и точные запросы сохранены локально в `source_art/supers_20260925/`; пофреймовые метаданные — `assets/characters/{hero}/super_gameplay_manifest.json`.

## Проверка

- `tests/arena_super_test.gd`: обе заставки, собственные герои, живые враги, два момента попадания, отсутствие дубля героя, границы портретного экрана, возврат в стойку, завершение миссии.
- `tests/assist_video_test.gd`: пауза, отсутствие раннего урона и пропуска, повторные callbacks, восстановление управления.
- `tests/solo_super_resume_test.gd`: три приёма подряд, новые враги, переход между волнами, сохранение прогресса и памяти.
- `tests/coop_super_test.gd` с обоими героями: личный урон и очки, сетевая пауза, выход из комнаты.
- `tests/coop_browser_test.cjs`: два изолированных браузера, настоящий WebRTC, второй телефон продолжает бой во время личного суперудара.

Кадры проверки стыка: `artifacts/arena_supers/{hero}_04_handoff_before.png` и `{hero}_05_handoff_after.png`.

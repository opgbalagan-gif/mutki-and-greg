# Ролики помощи

Подключён присланный 07.09 ролик для кнопки суперудара при игре за Гришу.

- `greg.ogv` — Гриша приходит на помощь Мутки; файл пока не добавлен, действует прежний боевой приём.
- `mutki.ogv` — присланный ролик с Мутки для суперудара игрока за Гришу. Длительность около 5,1 секунды, 720×1280, 24 кадра/с, исходный звук сохранён.

При полном заряде кнопка запускает ролик на весь экран с сохранением пропорций. Бой и фоновая музыка приостанавливаются. После завершения, «Пропустить» или Escape на арене появляется Мутки и выполняет фиолетовую волну из второго присланного ролика. Гриша остаётся на поле. Бой ждёт окончания приёма. Волна поражает живых врагов с обеих сторон один раз на кадре выпуска из ладоней; управление и музыка возвращаются после окончания анимации.

Анимация на арене: `source_art/animations/mutki/mutki_assist_super_20260907.mp4` — копия `hf_20260907_183829_867f60a8-f81c-4224-b921-e52e8aa1b792.mp4`. Извлечены 49 прозрачных кадров 1024×576, 12 кадров/с, длительность 4,08 секунды. Зелёный фон удалён с сохранением фиолетового свечения; масштаб и точка опоры постоянные, высота тела около 290 игровых пикселей. Ударный кадр — 22 (нумерация с нуля, исходный кадр 44, 1,83 секунды). Параметры сохранены в `assets/characters/mutki/assist_super_manifest.json`, обработка воспроизводится через `tools/extract_mutki_assist.py`.

В режиме на двоих ролик показывается на обоих телефонах независимо от того, кто играет за Гришу — P1 или P2. Если один пропустил видео, он ждёт другого. Только после окончания на обоих устройствах хост запускает общую анимацию и рассчитывает урон/очки Гриши. Анимация занимает место Мутки, его обычный спрайт временно скрыт, чтобы герой не дублировался. Кадры передаются второму телефону вместе с состоянием боя. Потеря связи приостанавливает видео и волну; выход из комнаты отменяет приём без запоздалого удара.

Исходник: `source_art/assists/greg_button_mutki_clip.mp4` (копия `hf_20260907_173317_98c67d66-1720-4430-b567-7febad50a093.mp4`). Преобразован локальным FFmpeg в Ogg Theora + Vorbis, качество видео 7, аудио 5; пакет увеличился примерно на 4,4 МБ.

Проверки: `tests/greg_super_video_test.gd` использует настоящий ролик и проверяет естественное завершение, пропуск, ударный кадр, однократный урон, запуск вторым игроком, сетевую паузу и выход во время видео. `COOP_TEST_SUPER=1` включает проверку этого сценария в `tests/coop_browser_test.cjs` через настоящие браузеры и WebRTC.

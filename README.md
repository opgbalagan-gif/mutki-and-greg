# MUTKI & GREG

Мобильный вертикальный файтинг на Godot 4.7.

Играть в браузере: https://opgbalagan-gif.github.io/mutki-and-greg/

## Управление

- Выберите персонажа в стартовом меню.
- Тапайте по арене, когда враг подошёл достаточно близко: удары переключаются автоматически.
- Попадания заполняют шкалу Greg Power.
- При полном заряде нажмите кнопку «СУПЕР УДАР».

## Содержимое текущей версии

- анимации стойки, четырёх ударов, получения урона и смерти Грега;
- анимации ходьбы, двух атак, получения урона и двух чередующихся смертей врага;
- стабилизированные размеры и положение персонажей между кадрами;
- новый фон площадки с роботом;
- звуки взмаха, попадания и падения;
- быстрые волны: на арену одновременно выходят группы до трёх врагов;
- все враги используют один и тот же полностью анимированный образ;
- каждый обычный враг побеждается за один-два удара;
- обычные удары Грега задевают первого и следующего врага в строю;
- здоровье, комбо и Greg Power;
- браузерная сборка в папке `docs/` для GitHub Pages.

## Запуск проекта

Откройте `project.godot` в Godot 4.7+ и запустите главную сцену. Проект использует вертикальное разрешение 720×1280; окно проверки на компьютере — 405×720.

## Проверка

```powershell
godot --headless --path . -- --smoke-test
```

Ожидаемый результат:

```text
SMOKE_TEST_PASS: select/spawn/attacks/hit/death/respawn/special/player-reactions
```
